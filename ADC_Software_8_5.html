What's new in ADC 8.5.4

  1. Fix: Existing offline product key no longer changes ADC 8.5 Standard branding to Pro without the actual Pro features.
  2. Added License & Edition page and Switch to Standard action; only the legacy licence record is removed, without deleting patient records.
  3. Removed licensed status wording from the titlebar and startup splash; the topbar now says Explore 8.5 Pro.
  4. Added Pro Features catalogue for 12 planned premium modules, clearly labeled Not yet released.
  5. Changed proposed Pro price to PKR 9,999 per month; 3 months shown at PKR 29,997, with no falsely enforced expiry.
  6. Added permanently visible release notes under Settings → Software Updates; all changes are also in update.json.
  7. Retained prior receipt discount lines, decorative non-scannable QR, smoother right drawer, developer options, and Kharian doctors directory.
  8. Security: Time-limited subscriptions and payment validation require an actual server-side license service in the future Pro release.
